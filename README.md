# Belleza que Decide

Sitio web instalable (PWA) para una directora de ventas independiente de belleza en Uruguay.

## Qué es

Una página propia, simple y pensada para el celular, que también se puede dejar en la pantalla de inicio del teléfono. No es una tienda ni una app de tienda de aplicaciones.

## Qué incluye

- Presentación de la directora y de su unidad.
- Folleto/catálogo del mes.
- Próxima clase de belleza, con inscripción.
- Contacto directo por WhatsApp.
- Catálogo de productos para mirar y un blog.
- Avisos a quienes instalaron la página, separados por tipo de audiencia.
