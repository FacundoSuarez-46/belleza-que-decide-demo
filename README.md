# Belleza que Decide

Página de Silvia, directora de belleza en Young. Una sola página, instalable en el teléfono. No es una tienda.

Reconstruida a partir de Aire (`belleza-que-decide-aire-43b86006ec.vercel.app`), con las fotos del Look de octubre y el hero de las tres juntas.

## Cómo verla

Abrí `index.html` o, en esta carpeta:

```
npx serve .
```
